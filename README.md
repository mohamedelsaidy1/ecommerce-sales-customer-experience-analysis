# E-Commerce Sales & Customer Experience Analysis

## Project Overview
This project analyzes e-commerce sales performance, customer behavior, delivery performance, and customer satisfaction using SQL and Power BI.

## Tools Used
- SQL Server
- Power BI
- Excel

## Dataset
The dataset includes:
- Customers
- Orders
- Order Items
- Payments
- Products
- Reviews

## Key Business Questions
- What is the total revenue and average order value?
- Which product categories generate the highest revenue?
- How does delivery performance affect customer reviews?
- Which states generate the most revenue?
- What is the distribution of customer review scores?

## Key Insights
- Total Revenue reached 16M+
- Average Review Score is 4.09
- Delayed orders receive significantly lower review scores
- São Paulo (SP) generated the highest revenue
- Beauty & Health products generated the highest sales revenue

## Dashboard Features
- Revenue trend over time
- Revenue by product category
- Revenue by state
- Delivery status analysis
- Customer review distribution
- Interactive filters
